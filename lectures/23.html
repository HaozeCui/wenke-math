文科高等数学　·　2.3 一般线性方程组

2.3　建议 2 学时

三张平面，
三种命运

线性方程组的解：唯一、没有、无穷多。几何上是平面怎么相交；代数上是增广矩阵出现 0=1 还是 0=0。投入产出把部门往来写成 (I−A)x=d。

三平面位置　·　通解含参　·　投入产出
目标

学完本讲，应能做到

01

能从「三平面」或阶梯形判断唯一解、无解、无穷解。

02

能写出含自由未知量的通解（参数写法）。

03

能说明投入产出模型把消耗写成矩阵后，要解 (I−A)x=d。

本讲路线

  • Ax=b 与增广矩阵
  • 高斯消元到阶梯形
  • 实验：三平面三种位置
  • 通解：自由未知量写成参数
  • 投入产出箭头
  • 齐次方程：永远至少有零解
定义

线性方程组

$n$ 个未知数、$m$ 个方程，写成 $A\mathbf x=\mathbf b$。增广矩阵 $[A|b]$ 把系数与常数放在一张表里。

行变换（换行、倍乘、倍加）不改变解集，目标是阶梯形。

实验 1

三条线的三种命运（平面的示意）

阶梯形上读结论

无解

  • 出现 $0=1$。
  • 几何：平行或三平面围成三角柱。

有解

  • 没有 $0=1$。
  • 主元个数 = 未知数个数：唯一。
  • 主元更少：无穷，多出来的未知数当参数。

课堂练 1

增广矩阵化成阶梯形后出现一行 [0 0 0 | 1]。方程组有解吗？ 若最后一行是 [0 0 0 | 0]，而秩小于未知数个数呢？

约 2 分钟。　·　按 A 揭晓解答

解答
解答

课堂练 1

  1. [0 0 0 | 1] 就是 0=1，无解。
  2. [0 0 0 | 0] 是 0=0，不增加约束。
  3. 若有效方程个数（秩）小于未知数个数，则有自由未知量，无穷多解。
先扫最右边那一列是否出现「左边全 0、右边非 0」。
定义

通解含参

把主元未知数用自由未知数表示。自由未知数改叫参数 $t,s,\ldots$。

例如 $x=1-t$，$y=2+2t$，$z=t$，即

$$\mathbf x=(1,2,0)+t(-1,2,1)$$

这是一条直线：特解 + 齐次通解。

特解给出一个点，参数扫出整条直线。

课堂练
先做

课堂练 2

已知 $x+y+z=2$，$y-z=1$，z 自由。令 $z=t$，写出 x、y 与向量形式。

约 3 分钟。　·　按 A 揭晓解答

解答
解答

课堂练 2

  1. y=1+t（因为 y−z=1）。
  2. x+ (1+t) + t=2 ⇒ x=1−2t。
  3. $\mathbf x=(1,1,0)+t(-2,1,1)$。
每个自由未知量贡献一个方向向量。

齐次 Ax=0

  • 永远有零解。
  • 若只有零解：列向量线性无关（方阵则 det≠0）。
  • 若有非零解：通解是若干方向的线性组合。
  • 非齐次的无穷解 = 一个特解 + 齐次通解。
定义

投入产出

部门之间互相消耗。直接消耗矩阵 $A$ 的元素 $a_{ij}$ 表示：生产一单位 $j$ 要消耗多少 $i$。

总产出 $x$，最终需求 $d$，满足

$$x=Ax+d\quad\Rightarrow\quad (I-A)x=d$$

能解这个方程组，才能问「最终多要一件衣服，农业要多产多少」。

箭 = 消耗。写成 (I−A)x = d 之后，才能问「最终需求对应多少总产出」。

课堂练 3　读模型

若某经济只有两个部门，$A=\begin{pmatrix}0.2&0.4\\0.3&0.1\end{pmatrix}$，$d=(1,1)^{\mathrm T}$。写出 $(I-A)x=d$ 的系数矩阵（不必解完）。

约 3 分钟。　·　按 A 揭晓解答

解答
解答

课堂练 3

  1. $I-A=\begin{pmatrix}0.8&-0.4\\ -0.3&0.9\end{pmatrix}$。
  2. 方程组 $0.8x_1-0.4x_2=1$，$-0.3x_1+0.9x_2=1$。
  3. 这是普通的二元线性方程组，可用克拉默或消元。
投入产出的新意在建模，不在新的消元法。

三种命运对照

唯一

三平面交于一点。主元满。

无解

0=1。平行或互相错开。

无穷

0=0 且未知数更多。交于一线或一平面。

秩：一句话

系数矩阵 A 的秩

  • 非零行个数，或主元个数。
  • 列向量里有多少个「独立方向」。

增广 [A|b] 的秩

  • 若比 A 的秩大：无解（多出 0=1）。
  • 若相等：有解。再与未知数个数比，决定唯一还是无穷。

课堂练 4

三个未知数，阶梯形有两行非零，且没有 0=1。解的几何图像是什么？要几个参数？

约 2 分钟。　·　按 A 揭晓解答

解答
解答

课堂练 4

  1. 秩 2 < 3，一个自由未知量，一个参数。
  2. 解集是直线（三维空间里一条线）。
  3. 三平面交于一条公共直线。

参数写法检查单

  • 自由未知量有几个，就写几个参数。
  • 主元未知数全部用参数表示，不要漏。
  • 写成「常向量 + 参数×方向」。
  • 代回原方程核对一组 t=0 与一组 t=1。

投入产出读题

x 是什么

  • 各部门总产出。
  • 既要满足最终需求，也要满足中间消耗。

d 是什么

  • 最终需求：被消费、出口的部分。
  • 不是总产出。
  • 给定 d，解 x。
公式

投入产出的最小数字

$$A=\begin{pmatrix}1/2&0\\ 0&1/2\end{pmatrix},\quad d=\begin{pmatrix}5\\ 5\end{pmatrix},\quad x=\begin{pmatrix}10\\ 10\end{pmatrix}$$

两部门都只消耗自己产出的一半，互不购买。$(I-A)x=d$ 就是每个方程 $\frac12 x_i=5$。最终各要 5，总产出各是 10。

公式

教材：三个部门互相买

$$A=\begin{pmatrix}1/5&1/3&0\\ 1/4&1/3&1/2\\ 0&1/5&1/5\end{pmatrix}$$

行是农业、工业、服务业。生产一单位工业要消耗 $1/3$ 单位农业。需求 $(6,10,2)$ 对应产出 $(20,30,10)$；需求改成 $(9,15,3)$，产出变成 $(30,45,15)$。消耗不是对角的，三个部门会一起变。

课堂练 5

若 I−A 不可逆，投入产出模型在数学上意味着什么？（不必联系具体产业。）

约 1 分钟。　·　按 A 揭晓解答

解答
解答

课堂练 5

  1. 对某些需求 d，可能无解或解不唯一。
  2. 通常表示消耗结构「太强」，系统不能稳定地对应到唯一总产出。
  3. 能连到 $\det(I-A)=0$ 即可。

解完以后做什么

  • 唯一解：代回原方程核对。
  • 无穷解：写出参数，抽两组数代回。
  • 无解：指出哪一行是 0=1，不要硬解。
公式

三种方程组，各写一个最小例子

$$\begin{cases}x+y=3\\ x-y=1\end{cases}\quad\begin{cases}x+y=1\\ x+y=2\end{cases}\quad\begin{cases}x+y=1\\ 2x+2y=2\end{cases}$$

第一组唯一解 $(2,1)$。第二组出现 $0=1$，无解。第三组两行是同一件事，$y$ 自由，$x=1-y$，无穷多解。未知数个数减秩，就是自由变量的个数。

三个平面

  • 一个三元一次方程是一张平面。
  • 唯一解：三张平面交于一点。
  • 无穷多解：交成一条直线，或三张重合；自由变量是 $1$ 个还是 $2$ 个，看秩。
  • 无解：没有公共点。先看增广矩阵里有没有 $0=1$，再谈几何。

三张平面，四种位置

先看有没有 0=1，再数秩。几何是这件事的图，不是另一套算法。

重合

$x+y+z=1$ 与它的 2 倍、3 倍是同一张平面。自由变量有两个。

平行

$x+y+z=1$ 与 $x+y+z=2$ 没有公共点。增广矩阵出现 $0=1$。

一点或一条线

三个方程交于一点时秩等于 3；交成直线时秩更小，通解含一个参数。

公式

教材上的三元：消完就是唯一解

$$\begin{cases}x_1+x_2+x_3=6\\ 3x_1+2x_2-x_3=4\\ 3x_1+x_2+2x_3=11\end{cases}$$

增广矩阵做行倍加，化成 $\begin{pmatrix}1&0&0&1\\ 0&1&0&2\\ 0&0&1&3\end{pmatrix}$。秩等于未知数个数 3，唯一解 $x_1=1$，$x_2=2$，$x_3=3$。代回第一式：$1+2+3=6$。

文化
文化卡片 · 列昂惕夫
投入产出把「谁消耗谁」写成矩阵，是经济学里最直接的线性代数。

列昂惕夫因此获诺贝尔经济学奖。往来是箭，箭是矩阵，最终需求是解方程组——系数不必估得很细。

带走与易错

带走

  • 先看 0=1 还是 0=0，再数自由未知量。
  • 通解 = 特解 + 参数×方向。
  • 投入产出：(I−A)x=d。

易错

  • 把 det=0 一律说成无解。
  • 通解不写参数，只列一个特解。
  • 以为必须估全行业数据才能写模型。

  • 自编一个出现 0=1 的增广矩阵。
  • 用自己的数写一个两部门的 (I−A)x=d，并解出来。
